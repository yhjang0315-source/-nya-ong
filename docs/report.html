6. 수상 패턴 분석

  1. 상이 기관별로 나뉩니다. 최우수상은 참여기관장상, 우수상은 후원사 대표상입니다. 2026년도 최우수 9점(참여기관장상), 우수 5점(후원사상) 구조라 특정 기관 데이터를 가장 잘 쓴 팀이 되는 전략이 현실적입니다.
  2. '지수 개발'형이 강합니다. 에너지 빈곤지표, 재해 위험지수, EVI, ECI처럼 새 지표를 정의하면 차별화가 쉽습니다.
  3. 입지 선정, 경로 최적화처럼 바로 쓸 수 있는 결과물이 대상과 최우수상에 많습니다.
  4. 데이터 1종만 깊게 써도 수상합니다 (3, 9, 10, 16번). 결합 개수보다 문제 정의가 중요합니다.
  5. 서비스 이름과 브랜딩이 있습니다 (Re:Career, 마음이).
